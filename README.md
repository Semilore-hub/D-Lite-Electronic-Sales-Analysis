# D-Lite-Electronic-Sales-Analysis
## Sales analysis project using Excel dashboard and pivot table
## PROJECT OVERVIEW
This project analyzes electronic sales data to uncover trends, revenue performance and product profitability using excel
pivot tables and dashboard
## OBJECTIVES
  - Analyze total sales revenue
  - Identify top-selling products
  - Determine the most profitable category
  - Evaluate Monthly Sales performance
## DATA CLEANING
  - Removed duplicates
  - Checked for missing values
  - Created calculated columns(Revenue, Profit)
## ANALYSIS TOOLS USED
  - Excel
  - Pivot Tables
  - Charts
  - Dashboard
